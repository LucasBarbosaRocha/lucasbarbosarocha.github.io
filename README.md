### Como publicar

1. Envie estes arquivos para a raiz de um repositório no GitHub, na branch `main`.
2. No repositório, abra **Settings > Pages**.
3. Em **Source**, escolha **Deploy from a branch**, depois `main` e `/ (root)`.
